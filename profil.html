Tentang Aplikasi

Aplikasi Perpustakaan Digital merupakan aplikasi berbasis web yang dirancang untuk mempermudah pencatatan dan pengelolaan transaksi peminjaman buku secara modern, efisien, dan terstruktur.

Fitur Aplikasi

  • 📋 Form transaksi peminjaman buku
  • 📊 Tabel daftar transaksi interaktif
  • 🧠 Validasi input menggunakan JavaScript
  • 📱 Tampilan responsif
  • 🎨 Desain modern dan user-friendly

Tentang Pengembang

Aplikasi ini dikembangkan sebagai bagian dari tugas Ujian Akhir Semester mata kuliah Pemrograman Web 1.

Tujuan pengembangan aplikasi ini adalah untuk menerapkan konsep HTML, CSS, dan JavaScript dalam membangun aplikasi web yang menarik dan mudah digunakan.
